# Attribution and scope

The underlying project is [ducnguyen67201/slam-research](https://github.com/ducnguyen67201/slam-research). The experimental files in this catalogue retain their existing comments and attribution. Many import or adapt the original project interfaces.

External models, solver implementations and datasets are not included. Original dependencies include Bosch Research XRefine, XFeat, Graph-Cut RANSAC, PyTorch, NumPy, SciPy and OpenCV. Their own licenses and dataset/model terms continue to apply; this repository does not relicense those projects.

For reference, the license texts from the local pinned upstream checkouts are retained under `licenses/`: XRefine (AGPL-3.0), XFeat (Apache-2.0) and Graph-Cut RANSAC (BSD-style license with separately licensed dependencies). Those texts identify the corresponding upstream projects, not a new blanket license for this catalogue.

The results include valid negative experiments, proxy-only studies, engineering-only code and source-only interfaces. Each page labels these distinctions. A higher control score or lower observed severe count is not automatically a deployable improvement, a causal effect or an original contribution.
